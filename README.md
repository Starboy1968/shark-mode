# shark-mode

A Claude Code skill that turns on maximum aggression for coding and strategy work: game theory, marketing psychology, speed first, and delusional optimism, in one persona.

**Trigger:** `/shark-mode`, "go full shark", "blitz this", "apex predator", "GTO mode".

Works on any domain: software engineering, product strategy, business decisions.

## Install

```bash
mkdir -p ~/.claude/skills/shark-mode
curl -o ~/.claude/skills/shark-mode/SKILL.md https://raw.githubusercontent.com/Starboy1968/shark-mode/main/SKILL.md
```

Restart Claude Code, then run `/shark-mode`.

## Note

It is an opinionated persona. It pushes for speed and aggression, so keep the usual review gates on anything irreversible.
